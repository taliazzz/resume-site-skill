# 免费托管平台对比与部署指引

> ⚠️ 平台 UI 与规则会随改版变化。以下为实测记录（实测时间：2025 年），入口名称、菜单层级以平台**实际 UI** 为准，使用前先核对。

## 三大免费平台对比

| 平台 | 国内访问 | 上线速度 | 坑 | 结论 |
|---|---|---|---|---|
| **Cloudflare Pages** | 可用 | 拖包后 ~1 分钟 | 注册需邮箱验证 | ✅ **推荐主路线**，无密码门、免费稳定 |
| Netlify Drop | 可用 | 最快（免注册拖包） | ⚠️ 未认领匿名站有**密码门**（密码印在页面上）且 **1 小时过期回收**；必须 Claim 注册才能公开 | 备用/试水 |
| 腾讯云 EdgeOne Pages | 最快（国内 CDN） | — | 入口难找；对 zip 分隔符敏感 | 国内速度优先时再走 |

补充：GitHub Pages 也是稳定免费选项，但国内访问速度不稳定，适合已有 GitHub 仓库的用户。

## Cloudflare Pages 部署主路线（实测走通）

1. 打开 `dash.cloudflare.com` 注册登录 → 邮箱验证（验证信可能进垃圾箱）
2. 左侧菜单「Workers 和 Pages」（或 Compute / Workers）→「创建」→「**直接上传**」（Direct Upload）
3. 项目名称：小写字母/数字/连字符（如 `resume-yourname`）→「创建项目」
4. 把打包好的 zip **拖进上传区** →「部署站点」
5. 部署完成显示「成功！您的项目已部署到以下区域：全球」→ 得到 `https://项目名.pages.dev`

**更新站点**：项目页（`…/pages/view/项目名`）→「创建新部署」→ 拖新 zip 覆盖 → **网址不变**。

## 腾讯云 EdgeOne Pages

- 入口：`edgeone.cloud.tencent.com/pages`（场景大厅 hover「创建项目」→ 直接上传）
- 对 zip 条目分隔符敏感，务必用 `scripts/pack.mjs` 打标准 zip
- 国内访问速度最优，适合投递国内公司时使用

## 求职场景要不要自定义域名？

不必须：默认域名免费 + HTTPS，HR 只点链接。自定义域名在国内需 ICP 备案（1-3 周），除非已有备案域名，否则不建议。
