# 图片抠图（可选步骤，纯 JS 方案）

> 仅当项目图是**彩色背景**截图、且想要「主体贴卡」效果时才需要。
> 纯白底图**不要抠**：贴白卡天然融合，且抠图会让图内白色元素（按钮、文字）消失——直接用原图裁顶展示即可。

## 方案：jimp（纯 JS，Windows 无原生依赖编译问题）

```powershell
npm.cmd install jimp@0.22.12
```

## 算法：region growing（边缘连通约束）

1. **基准色**：取图片顶左、顶右两个 5×5 区域的平均色，作为双基准色
2. **种子**：四条边的像素作为 BFS 种子
3. **扩散**：与**任一**基准色距 < bgTol **且边缘连通可达**的像素 → alpha=0
4. **软化**：紧邻透明区的像素 alpha=140，弱化锯齿边

「边缘连通性约束」是关键：它保证颜色接近背景但位于画面中央的主体不被误删。

## 参数调优（通常两轮）

- 浅色残留 → 加大 bgTol（如 45 → 80）
- 主体被误删 → 减小 bgTol 或检查基准色是否取到了主体区域

## 自检闭环（必须做）

抠图结果合成到白底拼图 → 用 Read 看图验收 → 不合格调参重跑。

## 展示分层（对应 index.html 三种 media 样式）

| 图片类型 | 处理方式 | CSS 类 |
|---|---|---|
| 透明底 cut.png | 完整显示（不裁剪 + 轻投影） | `tl-media` |
| 白底原图 | `object-fit:cover; object-position:top` 裁顶 | `tl-media--tall` |
| 横版截图 | 圆角小缩略图（保留文字） | `tl-media--thumb` |
